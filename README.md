# Lecture Notes · 강의 노트

다운로드한 강의를 자동으로 전사하고, 강의 옆에서 읽는 노트를 Obsidian 폴더에 저장하는 **Windows용 로컬 앱 + Chrome 확장 프로그램**입니다. JNUclass/Canvas와 YouTube 영상에 노트를 연결하고, 연결한 영상도 확장에서 다시 열 수 있습니다.

## 1. 다운로드하고 압축 풀기

**[Lecture Notes v0.1.3 다운로드](https://github.com/vividhyeok/Lecture-Notes/raw/refs/heads/main/downloads/Lecture-Notes-v0.1.3.zip)**

ZIP을 내려받아 `문서\Lecture-Notes`처럼 계속 사용할 폴더에 **모두 압축 풀기** 하세요. 압축 파일 안에서 바로 실행하지 마세요. 사용 후에도 이 폴더는 보관해야 합니다.

## 2. 처음 한 번 준비하기

필요한 프로그램은 **Windows 10/11, Chrome, Python 3.11 이상, FFmpeg**입니다. Obsidian은 선택 사항입니다.

1. Python이 없다면 [Python 공식 다운로드](https://www.python.org/downloads/windows/)에서 설치하세요. 설치 화면의 **Add python.exe to PATH**를 선택하세요.
2. 압축을 푼 폴더의 **SETUP.cmd**를 실행하세요. FFmpeg가 없으면 Windows 패키지 관리자로 설치를 시도합니다. 자동 설치가 안 되면 [FFmpeg Windows 빌드](https://www.gyan.dev/ffmpeg/builds/)의 `bin` 폴더를 PATH에 추가하세요.
3. 설치가 끝나면 창을 닫고 **START.cmd**를 실행하세요. 브라우저에 설정 화면이 열립니다.

## 3. 저장 위치 설정하기

설정 화면에서 다음 항목을 입력하고 반드시 **설정 저장**을 누르세요.

| 설정 | 입력할 내용 |
| --- | --- |
| OpenAI API 키 | 전사·AI 노트 생성에 사용할 키. ChatGPT 구독과 별도 API 요금이 발생합니다. |
| Obsidian 보관함 경로 | 노트를 쌓을 **기존 폴더의 전체 경로**. Obsidian 보관함 안의 하위 폴더도 가능합니다. |
| 자동으로 가져올 다운로드 폴더 | MP3 등이 저장되는 입력 전용 폴더. 노트 출력 폴더와 분리하세요. |
| 새 파일 자동 전사·노트 작성 | 다운로드 후 자동 처리를 원하면 켜세요. |

보관함 경로가 `D:\내 노트\jnuclass`라면 실제 노트는 `D:\내 노트\jnuclass\강의노트\과목명\강의명.md`에 저장됩니다. 전사본은 같은 과목의 `전사본` 폴더에 저장됩니다.

저장 버튼 아래의 **현재 노트 저장 위치**를 확인하세요. 저장 위치를 바꾸면 기존 노트도 새 위치에 복사되어 이어지고, 이전 파일은 보존합니다. API 키 없이도 기존 Markdown 노트 읽기·편집은 가능합니다.

## 4. Chrome에 확장 추가하기

1. Chrome 주소창에 `chrome://extensions`를 입력하세요.
2. 오른쪽 위 **개발자 모드**를 켜세요.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르세요.
4. 압축을 푼 Lecture Notes 폴더 안의 **extension 폴더**를 선택하세요. ZIP이나 상위 폴더를 선택하면 안 됩니다.
5. JNUclass 또는 YouTube 영상 페이지를 새로고침하세요.
6. Chrome 툴바의 확장 아이콘에서 **Lecture Notes**를 누르세요. 강의 페이지 오른쪽 가장자리의 **강의 노트** 버튼으로도 열 수 있습니다.

Chrome 웹 스토어 설치는 아직 지원하지 않습니다. 확장 추가 전에 **START.cmd를 먼저 실행**해야 이 PC의 연결 설정이 만들어집니다.

## 매일 사용하는 방법

1. PC를 다시 켰다면 **START.cmd**를 한 번 실행합니다.
2. 다운로드 도구의 저장 위치를 설정한 자동 입력 폴더와 맞춥니다.
3. MP3 다운로드가 끝나면 자동으로 전사·노트 생성이 시작됩니다. **내 강의**에서 과목 폴더와 강의를 선택합니다.
4. 영상 페이지를 연 상태에서 해당 노트의 **노트 관리 · 강의 연결 → 강의 연결**을 누릅니다.
5. 다음에 같은 영상을 열면 연결된 노트를 찾습니다. 반대로 내 강의의 **영상 열기**로 영상 탭을 열 수도 있습니다.

YouTube에 연결한 노트는 `youtube` 과목으로 모입니다. 이 확장 자체에는 영상 다운로드 기능이 없습니다. 사용 중인 다운로드 도구로 받은 오디오 파일을 가져옵니다.

과목별 자동 분류는 입력 폴더에 `운영체제\03 프로세스.mp3`처럼 하위 폴더를 만들거나 `[운영체제] 03 프로세스.mp3`처럼 파일명을 지정하면 됩니다. 수동 추가는 **내 강의 → 수동으로 파일 추가**를 펼치세요.

## 잘 안 될 때

| 증상 | 확인할 내용 |
| --- | --- |
| 자료함 연결 안 됨 | START.cmd 실행. 처음 설치 후에는 확장 관리에서 새로고침하고 영상 페이지도 새로고침. |
| 영상 페이지인데 연결 안 됨 | v0.1.3 이상으로 업데이트. 확장 관리의 사이트 액세스에서 현재 JNUclass/YouTube 사이트 허용. 원하는 영상 탭을 활성화한 뒤 연결. |
| 새 파일이 안 보임 | 실제 다운로드 위치와 자동 입력 폴더가 같은지 확인. 다운로드 완료 후 내 강의의 처리 상태 확인. |
| 설정한 위치에 노트가 없음 | 설정 저장 버튼 아래의 실제 경로 확인. 지정 폴더 아래 `강의노트\과목명`에 저장됨. |
| 전사 또는 노트 생성 실패 | API 키와 API 사용 한도 확인 후 처리 상태에서 재시도. |
| 동기화 대기 표시 | OneDrive/Obsidian 동기화 완료 여부 확인. 삭제한 노트는 자동 복원하지 않으므로 휴지통 확인. |

## 강의 연결 방식

강의 연결은 현재 탭의 URL·과목명·페이지 제목만 저장합니다. 영상 요소, iframe 접근, 재생 상태를 검사하지 않습니다. 연결한 페이지는 제목이 바뀌어도 URL이 같으면 같은 노트를 엽니다.

## 업데이트

설정에서 **처리 서버 종료** 후 새 ZIP을 같은 설치 폴더에 풀어 프로그램 파일을 덮어쓰세요. `.local`, `library`, `Obsidian` 및 개인 보관함은 지우지 마세요. START.cmd를 다시 실행하고 Chrome 확장 관리에서 Lecture Notes의 새로고침 버튼을 누른 뒤 열린 강의 페이지도 새로고침하세요.

## 데이터와 비용

노트와 전사본은 지정한 로컬 폴더에 저장됩니다. API 키·연결 키는 PC별 `.local`에 보관하고 GitHub/배포 ZIP에 포함하지 않습니다. 전사·AI 작성 시 해당 음성 또는 텍스트가 OpenAI로 전송되며 API 요금이 발생합니다. 브라우저 로그인 쿠키를 수집하지 않고 강의 출석·진도를 조작하지 않습니다.
