# Lecture Notes · 강의 노트

다운로드한 대학 강의를 자동으로 식별해 전사하고, 읽기 좋은 Markdown 노트와 시험 대비 자료로 정리하는 **Windows 로컬 앱 + Chrome 사이드 패널 확장 프로그램**입니다.

v0.2.2는 v0.2.0의 사용성 개편과 v0.2.1의 서비스 워커 복구에 더해, **예전 Lecture Notes 서버가 이미 실행 중이어도 START/UPDATE가 현재 폴더의 버전으로 자동 교체**하도록 업데이트 경로를 보강한 핫픽스입니다. Windows 로그인 시 처리 서버가 자동으로 실행되고, JNUclass/Canvas 강의 페이지에서 DownloadHelper로 받은 파일은 해당 강의와 자동 연결됩니다.

## 처음 설치

필요 환경: **Windows 10/11, Chrome, Python 3.11 이상, FFmpeg**. Obsidian은 선택 사항입니다.

1. 배포 ZIP을 계속 사용할 폴더(예: `문서\Lecture-Notes`)에 모두 압축 해제합니다. ZIP 안에서 직접 실행하지 마세요.
2. **SETUP.cmd**를 한 번 실행합니다.
   - FFmpeg가 없고 `winget`을 사용할 수 있으면 자동 설치를 시도합니다.
   - Windows 로그인 자동 시작을 등록합니다.
   - 시작 메뉴에 `Lecture Notes` 바로가기를 만듭니다.
   - 로컬 처리 서버를 바로 실행합니다.
3. 열린 Lecture Notes 설정 화면에서 OpenAI API 키와 노트 저장 위치를 지정합니다.
4. Chrome 주소창에 `chrome://extensions`를 입력하고 개발자 모드를 켠 뒤 **압축해제된 확장 프로그램을 로드합니다** → `extension` 폴더를 선택합니다.
5. JNUclass/Canvas 강의 페이지를 새로고침합니다.

이후에는 프로젝트 폴더에서 `START.cmd`를 매일 실행할 필요가 없습니다.

## 기존 버전에서 v0.2.2로 업데이트

가장 안전한 방법은 새 ZIP의 파일을 **Chrome이 현재 사용 중인 기존 Lecture-Notes 폴더 위에 그대로 덮어쓰는 것**입니다. 그러면 기존 `.local`, 자료함, Chrome의 압축해제 확장 경로를 그대로 유지할 수 있습니다.

1. 새 ZIP의 파일을 기존 Lecture-Notes 폴더 위에 덮어씁니다.
2. **UPDATE.cmd**를 실행합니다.
3. Chrome 확장 관리 화면이 열리면 `Lecture Notes · 강의 노트`의 **새로고침** 버튼을 한 번 누릅니다.
4. 이미 열려 있던 JNUclass/Canvas 페이지가 있다면 그 탭도 한 번 새로고침합니다.

`UPDATE.cmd`는 실행 중인 이전 서버를 종료하고 새 코드로 다시 시작하며, 자동 시작/시작 메뉴 등록도 갱신합니다. v0.2.2에서는 새 ZIP을 다른 폴더에 풀어 예전 설치의 API 토큰을 가지고 있지 않더라도, 18765 포트의 서버가 Lecture Notes임을 `/health`로 확인한 뒤 해당 구버전 프로세스만 종료하고 현재 버전을 시작합니다. 다른 애플리케이션이 포트를 사용 중이면 임의로 종료하지 않습니다.

배포 ZIP에는 `.local`, `library`, `Obsidian`이 포함되지 않으므로 기존 API 키·자료함·노트를 덮어쓰지 않습니다.

v0.2.1부터는 per-PC 설정 파일인 `extension/config.local.js`가 잠시 없더라도 서비스 워커 자체는 정상 등록됩니다. `SETUP.cmd` 또는 `UPDATE.cmd`가 실제 로컬 토큰 파일을 다시 생성합니다.

## 매일 사용하는 흐름

기본 사용은 아래 네 단계면 끝납니다.

1. PC를 켭니다. Lecture Notes 서버는 Windows 로그인 시 자동 시작합니다.
2. JNUclass/Canvas 강의 페이지를 엽니다.
3. Video DownloadHelper로 강의 음성/영상을 다운로드합니다.
4. Lecture Notes를 열면 해당 파일이 이미 **가져오기 → 강의 페이지 연결 → 전사 → 노트 작성** 파이프라인에 들어가 있습니다.

같은 영상 페이지를 다시 열면 연결된 노트를 자동으로 찾습니다. 내 강의의 영상 열기 버튼으로 원래 페이지를 다시 열 수도 있습니다.

자동 연결에 실패한 예외 상황에서만 노트 도구의 `강의 연결` 버튼을 사용하면 됩니다.

## 다운로드가 일반 음악과 섞이지 않게 하는 방식

설정에는 다운로드 폴더 경로가 있지만, v0.2.x의 기본값은 **폴더 전체 감시 OFF**입니다.

- **강의 페이지의 DownloadHelper 다운로드 자동 가져오기**: 켜기 권장. 실제 지원 강의 페이지에서 시작된 다운로드만 가져옵니다.
- **다운로드 폴더의 모든 지원 파일 자동 가져오기**: 끄기 권장. 켜면 해당 폴더의 일반 MP3/영상까지 강의 후보가 될 수 있습니다.
- **YouTube 다운로드도 자동 가져오기**: 기본 OFF. 음악 다운로드가 강의 목록에 섞이지 않도록 분리했습니다. YouTube 강의를 저장할 때만 켜세요.

앱 내부의 `library\inbox`는 명시적인 입력 폴더이므로 항상 자동 스캔합니다. 파일을 직접 넣어 자동 가져오기를 원할 때 사용하세요.

## 강의 목록과 보관함

강의 카드는 현재 처리 상태를 직접 표시합니다.

- 다운로드 완료 · 전사 대기
- 처리 중 · 전사 N/M 구간 완료
- 전사 완료 · 노트 작성 대기
- 완료 · 노트 준비됨
- 처리 실패 · 확인 필요

완료된 작업 로그는 계속 쌓아 보여주지 않고, **진행 중이거나 오류가 있는 작업만 처리 상태에 표시**합니다. 실패한 작업은 저장된 구간부터 재시도할 수 있습니다.

강의를 지우고 싶을 때는 우선 **보관**을 사용합니다. 보관은 비파괴적이며 원본 파일과 Obsidian 노트를 삭제하지 않습니다.

- 각 강의 오른쪽의 보관 버튼: 개별 보관
- `미분류 전체 보관`: 과거에 잘못 들어온 미분류 항목 일괄 정리
- `보관함`: 보관한 강의 확인
- `복원` / `모두 복원`: 다시 활성 목록으로 되돌리기

## AI 정리 품질

설정에서는 모델 ID 대신 기본적으로 품질 프리셋을 선택합니다.

| 프리셋 | 모델 | 용도 |
| --- | --- | --- |
| 빠름 | `gpt-5.6-luna` | 비용을 가장 아끼는 일상 강의 정리 |
| 균형 | `gpt-5.6-terra` | **기본 추천**, 품질과 비용의 균형 |
| 정밀 | `gpt-5.6-sol` | 복잡한 강의·시험 범위에 더 높은 품질 |
| 직접 지정 | 사용자 입력 | 고급 사용자용 |

기존 설치가 기본 `gpt-4.1-mini`를 사용 중이었다면 v0.2.x에서 `균형` 프리셋으로 마이그레이션합니다. API 사용 요금은 ChatGPT 구독과 별도입니다.

### 긴 강의노트 최종 일관성 정리

긴 강의는 먼저 여러 구간을 병렬로 정리한 뒤, 기본값에서는 **한 번 더 전체 일관성 패스**를 수행합니다.

이 최종 패스는 새 내용을 추가하는 용도가 아니라 다음만 정리합니다.

- 구간 경계에서 반복된 제목 제거
- 같은 개념의 용어 통일
- 끊어진 제목/불릿 계층 연결
- 중복 표현 정리
- 원래 강의 순서와 사실·수식·코드·예시는 보존

추가 API 호출이 싫다면 설정에서 `긴 강의노트 최종 일관성 정리`를 끌 수 있습니다.

## 시험 준비

시험 범위가 길어도 각 구간의 결과를 단순히 이어붙이지 않습니다.

1. 선택한 강의의 기존 전사본/노트를 사용합니다. 음성을 다시 전사하지 않습니다.
2. 긴 범위는 구간별로 핵심 개념·정의·비교·예시와 근거를 정리합니다.
3. 구간 결과 전체를 다시 통합해 중복을 줄이고 개념 관계를 맞춥니다.
4. 최종 통합 호출에 문제가 생기더라도 이미 완성된 범위별 정리본을 보존해 결과 손실을 막습니다.

시험 자료는 제공된 노트와 전사본에 근거해서만 작성하도록 설계되어 있으며, 자료에 없는 실제 출제 예측을 만들지 않습니다.

## 노트 읽기·수정

노트 화면의 보조 도구는 아이콘 중심으로 압축되어 있습니다. 아이콘 위에 마우스를 올리면 기능 설명이 표시됩니다.

주요 기능:

- 노트 편집
- Markdown 저장
- AI 다시 정리
- 현재 강의 페이지 수동 연결
- 원본 폴더 열기
- 과목/강의명 정리
- 기존 노트·전사본 연결
- A4 인쇄/PDF
- 전사본 GPT 보정용 복사/붙여넣기

노트 편집 중 Obsidian이나 다른 화면에서 같은 파일이 바뀌면 조용히 덮어쓰지 않고 충돌을 알려줍니다. 이전 버전은 원본 강의 폴더의 `versions`에 보관됩니다.

## 설정 권장값

일반적인 JNUclass 강의 사용이라면 다음을 권장합니다.

- 새 파일 자동 전사·노트 작성: **ON**
- 강의 페이지의 DownloadHelper 다운로드 자동 가져오기: **ON**
- 다운로드 폴더의 모든 지원 파일 자동 가져오기: **OFF**
- YouTube 다운로드도 자동 가져오기: **OFF**
- 정밀 시간 정보: 속도가 중요하면 **OFF**
- AI 정리 품질: **균형**
- 긴 강의노트 최종 일관성 정리: **ON**

## 문제가 생겼을 때

| 증상 | 확인할 내용 |
| --- | --- |
| `Service worker registration failed. Status code: 15` / `config.local.js failed to load` | **v0.2.1 이상으로 업데이트** → `UPDATE.cmd` 실행 → `chrome://extensions`에서 Lecture Notes 새로고침. |
| `START.cmd`를 눌러도 예전 버전이 열림 | **v0.2.2 이상으로 업데이트**. v0.2.2의 START/UPDATE는 실행 중 서버 버전을 확인하고 구버전이면 현재 폴더 버전으로 교체합니다. |
| 자료함 연결 안 됨 | 시작 메뉴에서 `Lecture Notes` 실행 → 확장에서 `다시 확인`. 프로젝트 폴더를 찾을 필요 없음. |
| 업데이트했는데 예전 동작 | `UPDATE.cmd` 실행 후 `chrome://extensions`에서 Lecture Notes 새로고침. 열린 LMS 탭도 새로고침. 새 폴더를 사용했다면 Chrome이 그 폴더의 `extension`을 가리키는지도 확인. |
| 강의 다운로드가 안 들어옴 | DownloadHelper 자동 가져오기 ON, 다운로드 위치와 설정 폴더 일치 여부 확인. |
| 일반 MP3가 들어옴 | `다운로드 폴더의 모든 지원 파일 자동 가져오기`를 OFF로 변경. 기존 항목은 `미분류 전체 보관`. |
| YouTube 파일이 안 들어옴 | YouTube 자동 가져오기는 별도 옵션이며 기본 OFF. |
| 자동 연결 안 됨 | 다운로드를 시작할 때 실제 강의 탭이 활성 상태였는지 확인. 이미 가져온 강의는 수동 `강의 연결`로 복구 가능. |
| 전사/노트 생성 실패 | OpenAI API 키·프로젝트 사용 한도·처리 상태의 오류 메시지 확인 후 재시도. |
| 노트가 지정 위치에 없음 | 설정의 Obsidian 보관함 경로와 `강의노트\과목명` 폴더 확인. |
| 동기화 대기 | OneDrive/Obsidian 동기화 및 휴지통 확인. 삭제된 노트를 자동 복원·재전사하지 않음. |

## 데이터와 보안

- 서버는 `127.0.0.1` 로컬 루프백에서만 동작합니다.
- API 키와 연결 토큰은 PC의 `.local`에 저장되며 배포 ZIP/GitHub에 포함하지 않습니다.
- 전사 시 음성, 노트/시험 자료 생성 시 해당 텍스트가 OpenAI API로 전송됩니다.
- 브라우저 로그인 쿠키를 수집하지 않습니다.
- 강의 출석·진도를 조작하지 않습니다.
- 보관 기능은 파일 삭제가 아닙니다.
