# Lecture Notes

강의를 보면서 옆에서 읽는 노트, 시험 기간에도 다시 쓰는 전사본.

Video DownloadHelper로 받은 MP3를 OpenAI로 전사하고, 원문 흐름을 살린 Obsidian Markdown 노트를 과목별로 저장하는 **별도 Chrome 확장 프로그램 + 로컬 자료함**입니다. Lecture Notifier와 함께 사용할 수 있습니다.

## 지금 이 PC에서 시작하기

1. **START.cmd**를 두 번 클릭합니다. 설정 화면이 브라우저에서 열립니다.
2. **OpenAI API 키**를 입력합니다. ChatGPT 구독과 별도로 API 사용 요금이 발생합니다.
3. **Obsidian 보관함 경로**를 지정합니다. 기본값은 이 프로젝트의 `Obsidian` 폴더입니다. 기존 보관함을 쓰려면 그 보관함 폴더의 전체 경로를 입력하세요.
4. **자동 입력 폴더**를 확인하고 설정을 저장합니다. 처음에는 `library/inbox`만 감시합니다.
5. Chrome 주소창에 `chrome://extensions` 입력 → 개발자 모드 → 압축해제된 확장 프로그램 로드 → **이 프로젝트의 `extension` 폴더**를 선택합니다.
6. JNUclass 강의를 열고 오른쪽 가장자리의 **강의 노트** 버튼을 누릅니다. Chrome 툴바의 확장 아이콘을 눌러도 열립니다.

이미 Python과 FFmpeg가 설치된 이 PC에서는 별도의 패키지 설치가 필요 없습니다. 다른 PC는 Python 3.11 이상과 FFmpeg가 필요합니다. `SETUP.cmd`에서 설치 상태를 확인할 수 있습니다.

브라우저 확장만으로 닫힌 창에서도 폴더를 감시하고 긴 파일을 처리하기 어려워 **로컬 처리 서버가 함께 실행**됩니다. 창을 닫아도 처리 서버는 계속 동작합니다. PC를 재시작한 뒤에는 START.cmd를 실행하세요. 종료는 설정 화면 하단에서 할 수 있습니다.

## 가장 간단한 사용법

### 영상과 노트 연결·이전 다음 강의

- **내 강의**는 과목 폴더와 강의 목록을 먼저 보여줍니다. 자동 입력 폴더가 기본이며, 직접 파일을 넣을 때만 아래의 **수동으로 파일 추가**를 펼치세요. 처리 상태도 접어서 표시합니다.
- **YouTube** 영상도 연결할 수 있습니다. 노트의 **노트 관리 · 강의 연결 → 강의 연결**을 누르면 `youtube` 과목으로 모입니다. 영상 ID를 저장하므로 같은 제목의 다른 영상과 구분됩니다.
- 한 번 연결한 영상은 내 강의의 **영상 열기**, 노트 상단의 **강의 영상 열기**로 새 탭에서 열 수 있습니다. JNUclass는 로그인 상태가 필요할 수 있습니다.
- 편집·이름 정리·AI 다시 정리·파일 연결은 **노트 관리**, 글자 크기와 PDF는 **글자 크기 · 인쇄**를 펼쳐 사용합니다.

- LMS 영상 탭을 연 상태에서 사이드 패널로 원하는 노트를 열고 **강의 연결**을 누르세요. 버튼을 누른 순간의 과목명·영상명과 영상 식별 정보를 현재 노트에 연결합니다. 다른 노트에 연결했던 영상은 새 노트로 연결을 옮깁니다.
- 다음에 같은 영상을 열면 연결한 노트를 자동으로 엽니다. 연결이 없을 때는 과목명과 영상명(파일 확장자·밑줄·공백 차이 무시)이 일치하는 노트가 하나일 때만 자동으로 엽니다. 비슷한 이름이나 중복 후보는 임의로 선택하지 않습니다.
- 노트 상단의 **이전 / 강의 목록 / 다음**으로 같은 과목 문서를 이동합니다. 강의명 숫자 순서를 인식하므로 `02`, `03`, `10` 순으로 정렬됩니다. 이름·과목은 **이름 정리**에서 수정하세요. 문서를 수동으로 넘긴 뒤에는 영상이 바뀌기 전까지 자동으로 원래 노트로 돌아가지 않습니다.
- 영상 연결은 Obsidian의 `_관리` 파일과 동기화되며 탭 번호에 의존하지 않습니다. 다른 PC에서도 같은 보관함을 지정하면 재사용합니다. 로그인 토큰·서명 쿼리는 연결 정보에 저장하지 않습니다. 재생·출석·진도는 조작하지 않습니다.
- Lecture Notifier(`okfidijgnafbfdkcoibhabigblpanhnn`)의 과목 경로 및 영상 주변 제목 탐색 순서를 사용합니다. v0.1.1부터 일부 iframe에 접근하지 못해도 영상 페이지의 주소와 제목으로 연결할 수 있습니다.

- **학습 구조로 다시 정리:** 노트 화면의 `AI 다시 정리`는 저장된 전사본으로 내용 중심 중제목·소제목과 의미에 따른 다단계 목록을 새로 작성합니다. STT는 다시 하지 않으며 텍스트 AI 비용만 발생합니다. 이전 노트는 백업하고, 생성 도중 수정된 노트는 덮어쓰지 않습니다. 기존 노트의 수동 추가 내용은 새 결과에 자동 합쳐지지 않으므로 백업을 확인하세요.

- **파일 하나:** 패널의 `내 강의`에 MP3를 놓습니다. 과목명을 입력하면 해당 과목 폴더에 저장됩니다. 강의명을 비워두면 파일명을 사용합니다.
- **다운로드 자동 처리:** Video DownloadHelper의 저장 폴더를 설정의 입력 폴더와 맞춥니다. 다운로드가 완료되고 파일이 안정되면 전사와 노트 작성을 시작합니다. 패널을 열어 둘 필요 없습니다.
- **폴더로 분류:** `inbox/운영체제/03 프로세스.mp3`처럼 과목명 하위 폴더에 넣으세요.
- **파일명으로 분류:** `[운영체제] 03 프로세스.mp3` 또는 `운영체제__03 프로세스.mp3`도 인식합니다.
- **기존 전사본:** TXT, SRT, VTT, JSON, Markdown을 놓으면 STT 없이 가져옵니다.
- **기존 강의노트:** 파일명에 `노트`, `note`, `요약`이 있는 MD는 그대로 읽고 보관합니다. 자동으로 다시 작성하지 않습니다.
- **같은 강의에 파일 추가:** 노트 읽기 → `기존 노트·전사 연결`로 이미 있는 전사본이나 강의노트를 붙일 수 있습니다. 전사본 파일은 전사본으로, 이름에 `노트`가 있는 MD는 노트로 연결합니다.

과목명이 자동으로 잡히지 않는 페이지는 패널에서 한 번 입력하세요. LMS 제목 구조가 강의마다 달라 강의명 추출이 항상 정확하지는 않습니다. `이름 정리`로 언제든 수정할 수 있습니다. 분류 변경 시 이전 경로의 파일은 보존합니다.

## Obsidian에 쌓이는 파일

```text
선택한 Obsidian 보관함/
├─ 강의노트/
│  ├─ 운영체제/
│  │  ├─ 01 프로세스.md
│  │  ├─ 02 스레드.md
│  │  └─ 전사본/
│  │     ├─ 01 프로세스.md
│  │     └─ 02 스레드.md
│  └─ 자료구조/
│     └─ 01 연결 리스트.md
└─ 시험대비/
   └─ 중간고사 대비-고유번호.md
```

Obsidian에서는 해당 폴더를 **보관함으로 열기**만 하면 됩니다. 플러그인은 필요 없습니다. Obsidian을 설치하지 않아도 일반 Markdown 파일로 사용할 수 있습니다.

- 패널과 Obsidian은 **같은 노트 파일**을 읽습니다. Obsidian에서 편집하면 패널에도 반영됩니다.
- 패널에서 편집 후 저장하면 같은 파일에 저장합니다. 이전 내용은 `library/lectures/.../versions`에 보관합니다.
- 편집 중 다른 화면에서 변경되면 저장을 차단해 오래된 내용으로 덮어쓰는 일을 막습니다. 자신의 편집 내용을 복사하고 최신 노트와 합쳐 주세요.
- 같은 제목의 기존 파일이 있으면 고유번호를 붙여 보존합니다.
- 한 번 저장된 노트·전사본이 없어지면 동기화 대기로 표시하고 자동 복원하거나 재전사하지 않습니다. 삭제한 파일은 Obsidian 휴지통이나 사용 중인 동기화 서비스에서 복원하세요.

## 다른 PC에서 이어서 사용하기

### 읽기 화면과 인쇄

- 오른쪽 위 테마 버튼: 자동(PC 설정 따름) → 밝게 → 다크 모드 순서로 전환합니다.
- 노트의 `가− / 100% / 가+`: 본문 글자를 80~160%로 조절합니다. 가운데 비율을 누르면 기본 크기로 돌아갑니다. 화면 설정은 각 PC·브라우저에 저장되어 다른 PC의 화면 크기에 영향을 주지 않습니다.
- `A4 인쇄 / PDF`: 현재 보고 있는 노트·전사본·시험 자료를 별도 미리보기로 엽니다. 인쇄 글자 크기를 선택하고 `인쇄 / PDF 저장`을 누르세요. 다크 모드여도 흰 배경으로 본문만 출력합니다. 인쇄 대화상자에서 용지 A4, 배율 100%, 머리글·바닥글 끄기를 권장합니다.
- 인쇄 미리보기에는 저장된 본문을 사용합니다. 편집 중이면 먼저 저장 또는 취소하세요.

### 같은 보관함 연결

1. Obsidian에서 같은 보관함을 동기화합니다. `강의노트`와 `시험대비` 폴더를 모두 포함하세요. `강의노트/_관리`도 함께 동기화해야 강의 목록이 복구됩니다.
2. 새 PC에도 이 프로그램을 별도로 압축 해제하고 `SETUP.cmd`, `START.cmd`를 실행합니다. Chrome에서 해당 PC의 `extension` 폴더를 다시 불러옵니다.
3. 설정에서 **그 PC의 Obsidian 보관함 경로**를 지정합니다. 약 5초 후 동기화된 강의와 전사본이 자동 등록됩니다. 읽기는 API 키 없이 가능하며, AI 생성이 필요할 때만 해당 PC에서 API 키를 설정하세요.
4. 다운로드 감시 폴더도 PC마다 지정합니다. 프로그램 폴더와 `.local`은 동기화하지 마세요. API 키·로컬 연결 키·작업 대기열은 PC별로 관리됩니다.

관리 정보는 일반 Markdown 파일에 보관함 기준 상대 경로로 저장합니다. 드라이브나 Windows 사용자명이 달라도 사용할 수 있습니다. 원본 MP3는 보관함에 복사하지 않으므로 다시 내려받거나 재전사할 필요 없이 전사본·노트만으로 시험 자료를 만들 수 있습니다. 기존 시험 결과도 함께 표시됩니다.

파일이 일부만 도착했거나 비어 있으면 노트 화면에 동기화 대기가 표시됩니다. 잘못된 관리 파일은 덮어쓰지 않고 설정 상태에 오류를 남깁니다. 같은 파일을 동시에 편집할 때는 저장 전 변경 여부를 확인하고, 읽어 온 이전 본문을 `_관리/변경이력`에 보관합니다. 동기화 서비스의 충돌 사본은 자동 병합·삭제하지 않습니다. 여러 PC의 동시 편집을 완전히 잠그는 기능은 없으므로 PC를 바꾸기 전 동기화를 완료하세요.

파일명·과목 변경은 확장 화면에서 하면 다른 PC에도 전달됩니다. Obsidian에서 파일을 직접 이동한 경우 기존 위치를 찾지 못해 대기로 표시될 수 있으므로 원래 위치로 되돌린 뒤 확장의 이름 변경 기능을 사용하세요. 삭제는 파일을 자동 복원하지 않지만, 강의 목록 항목 자체는 남겨 누락을 확인할 수 있습니다.

원본 오디오, 구조화된 전사본, API 처리 캐시는 `library/lectures/`에 별도 보관합니다. `.local/`에는 설정·연결 키·작업 색인이 있습니다. **프로젝트 폴더 전체를 지우면 안 됩니다.**

## 노트 작성 방식

사용자가 제공한 아래 지침을 그대로 생성 기준으로 사용합니다.

> 원문의 순서와 흐름 유지. 내용은 삭제하지 않고 전부 살리되 반복·군더더기 압축. 문맥상 명확한 오타·STT 오류만 수정. 외부 지식 추가 금지. 제목/소제목과 중첩 unordered list 중심. 중요한 내용은 상위, 설명·예시·부연은 하위. 의미가 유지되는 범위에서 조사·어미 축약. 형광펜·밑줄·과한 강조·이모지 없이 읽기 쉽고 Ctrl+F 가능한 구조.

노트 생성용 입력을 순서대로 나누고, 모든 구간 결과를 순서대로 이어 붙입니다. 별도로 원본 전사본 전체도 보존합니다. AI가 모든 세부를 빠짐없이 보존하거나 STT 오류를 모두 수정한다고 보장할 수는 없으므로 전사본과 함께 확인하세요.

패널은 중첩 목록, 제목, 표, 코드 블록, Obsidian 위키 링크의 표시를 지원합니다. **수동 스크롤이 기본**이고, 재생 위치 때문에 스크롤이 튀지 않습니다. 노트 읽기에서 Ctrl+F를 누르면 노트 내 검색을 할 수 있습니다. LaTeX 수식과 Obsidian 플러그인 전용 문법은 원문 텍스트로 보입니다.

## 속도와 API 사용

- 기본 STT: **gpt-4o-mini-transcribe**, 정밀 시간 정보 생략.
- 긴 오디오는 FFmpeg로 10분 구간으로 나눠 **최대 3개 동시 전사**합니다.
- 정밀 시간 정보가 필요한 경우에만 설정에서 Whisper 모드를 켭니다. SRT도 보관됩니다.
- 노트·시험 자료 기본 모델: **gpt-4.1-mini**. 설정에서 사용 가능한 텍스트 모델로 바꿀 수 있습니다.
- 같은 내용의 파일은 해시로 중복을 막습니다. 노트 작성 실패 후 재시도할 때도 완료한 전사를 재사용합니다.
- 성공한 구간별 API 결과를 저장합니다. 통신이 끊겨 응답을 받지 못한 요청은 재시도 시 다시 과금될 수 있습니다.
- 이미 완성된 노트는 버튼을 눌러도 자동 덮어쓰지 않습니다. 직접 편집하거나 새 전사·노트 파일을 연결하세요.

API 키는 Windows DPAPI로 암호화해 이 PC의 현재 계정에 보관합니다. 확장 파일에는 OpenAI API 키가 들어가지 않습니다. 입력한 음성과 전사 텍스트는 요청한 전사·AI 처리를 위해 OpenAI로 전송됩니다. 응답 생성 요청은 `store: false`로 보냅니다. 이것이 API 제공자의 모든 로그 보관을 비활성화한다는 뜻은 아닙니다.

## 시험 기간에는 재전사 없이

두 가지 방식 중 편한 것을 사용하세요.

1. **패널에서 선택:** 시험 준비 → 강의 체크 → 자료 제목 입력 → 시험 자료 만들기.
2. **파일만 넣기:** `library/exam-inbox`에 전사본·강의노트 파일들을 넣습니다. 자동 처리가 켜져 있으면 안정된 파일 집합을 읽어 시험 자료를 만듭니다. 폴더를 비우고 다음 과목 자료를 넣으면 범위가 분리됩니다. 이전 결과는 유지됩니다.

원본 자료 모음, 핵심 개념, 비교, 자가점검 문제·답, 근거와 확인 필요 항목을 Markdown으로 생성합니다. 이 과정에서는 **오디오 STT를 호출하지 않습니다**. 자료가 같으면 같은 시험 작업을 재사용하고, 파일이 바뀌면 새 결과를 만듭니다. 매우 큰 범위는 순서대로 구간별 정리를 합쳐 모든 입력 범위를 포함합니다.

## Video DownloadHelper 연결 범위

확인한 확장 ID `lmjnegcaeklhafolokijcfjliaokphfk`는 **Video DownloadHelper**이며 이 PC에 설치된 버전은 10.5.24.2입니다.

설치본에서 문서화된 외부 다운로드 제어 API는 확인하지 못했습니다. 따라서 다운로드 버튼 자체를 강제로 누르거나 확장 내부 파일을 수정하지 않습니다. **사용자가 다운로드한 파일을 자동으로 이어받아 처리**합니다.

Chrome 다운로드 이벤트로 완료를 감지하는 옵션과 로컬 폴더 감시를 함께 제공합니다. DownloadHelper가 Chrome 바깥의 도구로 저장하더라도 지정한 폴더에 파일이 생기면 처리할 수 있습니다. 과목별 폴더/파일명 방식이 가장 확실합니다. LMS 쿠키·인증 토큰을 가져오거나 출석·진도·영상 재생을 조작하지 않습니다.
